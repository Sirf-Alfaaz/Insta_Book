InstaBook - Social Media Platform
InstaBook is a dynamic social media platform where users can connect with friends, share posts, and communicate in real-time. It is built using HTML, CSS, JavaScript, and PHP.

Features
-User registration and login

-Profile creation and management

-Post text and images

-Real-time chat with friends

#Follow and interact with other users

Technologies Used
Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL (for storing user data, posts, and messages)

Installation
Clone this repository to your local machine:
git clone https://github.com/your-username/instabook.git

Navigate to the project directory:
cd instabook

-Set up your local server (e.g., XAMPP or WAMP) and place the project folder in the htdocs (XAMPP) or www (WAMP) directory.

-Import the instabook.sql file into your MySQL database (found in the project folder) to set up the necessary tables.

-Update your database connection settings in the config.php file.

Access the app through your local server:
http://localhost/instabook/
